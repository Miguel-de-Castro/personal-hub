O que funciona hoje e o que ainda falta

O app está em construção. Esta lista foi conferida no código, não é promessa.

Funciona

  • Criar tarefas, tópicos de estudo, vagas e entradas de diário.
  • Concluir tarefas, com atualização imediata na tela.
  • Alternar entre dados de exemplo e dados próprios.
  • API completa, com validação, para os quatro recursos.

Em desenvolvimento

  • Busca, notificações e filtros: estão na tela, mas não fazem nada.
  • Atalhos Quick Log e New Task da barra superior.
  • Editar e excluir pela interface. A API já aceita, a tela ainda não.
  • Menu dos cartões de vagas, barra de formatação do diário e página Support.

Decisões técnicas

Sem banco de dados e sem conta, mas com os cuidados de uma API de verdade.

API só para esta máquina
Escuta em 127.0.0.1 e recusa requisições com Host ou Origin que não sejam localhost, o que barra outros sites abertos no navegador e DNS rebinding.
Validação sem dependências
Cada recurso declara os campos aceitos e o tipo de cada um. Campos desconhecidos são descartados, links só podem ser http(s) e id e createdAt vêm do servidor.
Escrita atômica e serializada
As gravações passam por uma fila de promises e vão para um arquivo temporário antes de um rename. Duas edições seguidas não se misturam e uma queda não deixa JSON pela metade.
Um roteador CRUD para tudo
Tarefas, tópicos, vagas e diário usam o mesmo roteador genérico, createResourceRouter, com schema e construtor próprios.
Demo que nunca envelhece
Na primeira execução, as datas do conjunto de exemplo são deslocadas para o dia atual. As empresas do exemplo são fictícias.

Stack

web React 18, TypeScript, Vite, Tailwind CSS v4, shadcn/ui (Base UI), React Router

server Express 5, TypeScript (tsx), armazenamento em arquivo JSON

repo monorepo com npm workspaces, licença MIT

Como rodar localmente

Não há versão hospedada: o app foi feito para rodar só na sua máquina. Precisa de Node.js 20.19+ ou 22.12+.

Na primeira leitura ou gravação, o servidor cria server/data/db.json a partir do arquivo de exemplo, já em modo de dados de exemplo.

git clone https://github.com/Miguel-de-Castro/personal-hub.git
cd personal-hub
npm install
npm run dev

A API sobe em localhost:4000 e o app em localhost:5173.
